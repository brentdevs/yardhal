# Yardhal

A native Android IRC client for Android 13+, built with Kotlin and Jetpack
Compose. Port of the layered architecture used by the Halyard iOS client:
strict module layering, a pure-function inbound reducer, and a real-server
integration harness.

Development happens on `feature/full-client` — see the pull request for the
full implementation and `docs/architecture.md` inside it for orientation.
